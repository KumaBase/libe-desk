# Libe Desk

[リベシティ](https://libecity.com/)（および関連サービス）を、ひとつのデスクトップアプリから使えるようにする**非公式**アプリです。リベシティ運営とは関係ありません。

## できること

- サイドバーからリベシティ本体や関連サービスを開く
- 「よく使う」にピン留めして、よく使うリンクをすぐ呼び出す（リベシティは常時表示）
- リベシティのプロフィールに出る★でお気に入りユーザーを登録し、サイドバーからプロフィールを開く
- 複数タブでページを行き来する（上部の移動用スペースとタブ帯を分離）
- 戻る / 進む / 再読み込み
- リベシティ関連のページはアプリ内で開き、それ以外のサイトは確認後にブラウザで開く

初回のウィンドウサイズは原則1400×900です。画面に収まるよう調整し、終了時のサイズと拡大状態を次回起動時に復元します。

ウィンドウを動かすときは、最上部の「Libe Desk」と表示された帯をドラッグしてください。同じ帯をダブルクリックすると、フルスクリーンにせず拡大／元のサイズに戻せます。タブが増えてもこの移動用スペースは残ります。タブはドラッグ＆ドロップで並べ替えられます。青い線が挿入位置を示し、端までドラッグすると横スクロールします。タブ帯の外で離すか Esc キーでキャンセルできます。タブは横スクロールでき、閉じるボタンと選択中のタブを見分けやすくしています。

macOSでは「Libe Desk」メニューの「Libe Deskを終了」、または `⌘Q` で終了できます。`⌘T` は新しいタブ、`⌘W` は現在のタブを閉じます（最後のタブを閉じるとリベシティを開き直します）。「ウィンドウ」メニューから最小化・拡大／縮小もできます。

サービスメニューは2026年9月6日のリベシティのホーム・「もっと見る」を確認して更新しています。外部ブラウザで開く項目には `↗` を表示し、確認ダイアログを挟みます。メニューは自動同期ではありません。

## ダウンロード

[公式の GitHub Releases](https://github.com/KumaBase/libe-desk/releases) から、お使いの OS 向けのインストーラーをダウンロードしてください。第三者が再配布しているファイルは使用しないでください。

| OS | ファイル |
|---|---|
| macOS | `.dmg` |
| Windows | `.msi` または `.exe`（NSIS） |
| Linux | `.AppImage` または `.deb`（ベストエフォート） |

### ダウンロードしたファイルの確認

各 Release に添付される `SHA256SUMS` を開き、ダウンロードしたファイルの SHA-256 値と一致することを確認してください。

macOS / Linux:

```bash
shasum -a 256 <ダウンロードしたファイル>
```

Windows PowerShell:

```powershell
Get-FileHash <ダウンロードしたファイル> -Algorithm SHA256
```

`SHA256SUMS` がない Release、値が一致しないファイル、入手元を確認できないファイルは実行しないでください。配布物を使わず、[ソースからビルド](./docs/development.md)することもできます。

### 署名と対応する配布物

現在のmacOS Apple Silicon版は、Kuma Base LLCのDeveloper ID署名・Apple公証済みです。DMGを開き、アプリをApplicationsへドラッグしてインストールしてください。更新時はLibe Deskを終了してから既存のアプリを置き換えます。

Intel Mac版は現在の配布対象外です。Windows・Linux版は過去のリリースの配布物で、今回の更新は含みません。各リリースの対応環境と署名状況を確認してください。

以下は過去の未署名版や開発ビルド向けの案内です。まず入手元とチェックサムを確認してください。

### macOS「開発元を確認できないため開けません」

1. インストールしたアプリを Finder で右クリック（または Control クリック）
2. 「開く」を選ぶ
3. ダイアログでもう一度「開く」を選ぶ

一度この手順で開けば、次回以降は通常どおり起動できます。

### Windows「Windows によって PC が保護されました」

1. 「詳細情報」をクリック
2. 「実行」をクリック

## 更新と対応環境

- 自動更新機能はありません。新しい版は [Releases](https://github.com/KumaBase/libe-desk/releases) から手動でインストールしてください。
- macOS と Windows を主な対象とし、Linux はベストエフォートです。対応状況は各 Release の説明を確認してください。
- 前回終了時のタブ構成は復元しません。
- 複数アカウントの切り替えには対応していません。
- 外部ドメインへの移動時は確認ダイアログを表示し、承認した場合だけ標準ブラウザで開きます。ログイン・決済などの途中で画面が切り替わる場合があります。

## データとプライバシー

- Web ページは OS 標準の WebView（macOS: WKWebView、Windows: WebView2、Linux: WebKitGTK）で表示します。
- ログイン情報を Libe Desk 独自のサーバーへ送る機能はありません。現行ソースコードには、独自サーバー、アクセス解析、テレメトリーへの送信処理もありません。
- 表示した Web サイトは、通常のブラウザと同様に各サービスおよびその配信先と通信します。各サイトによるデータの取り扱いは、各サービスの規約・プライバシーポリシーに従います。
- Cookie やサイトの保存データは OS WebView が端末内で管理します。ログイン状態がタブ間やアプリ再起動後にも残る場合があります。共有端末では使用後にサイトからログアウトしてください。
- 「よく使う」の設定はアプリのローカルストレージに保存します。
- お気に入りユーザーは、この端末のアプリ設定ディレクトリ内の `favorites.json` に保存します。保存するのはユーザー ID と表示名だけで、リベシティへ送信することはありません。
- アプリのアンインストールだけでは WebView のサイトデータが残る場合があります。端末を譲渡・廃棄する場合は、OS のアプリデータも削除してください。

セキュリティ上の問題を見つけた場合は、公開 Issue へ詳細を書かず、[セキュリティポリシー](./SECURITY.md)に従って報告してください。
