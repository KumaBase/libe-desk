# 要求メモ（アーカイブ）

初期検討時の要求メモです。現行の仕様は [spec.md](./spec.md) を参照してください。

リポジトリ: https://github.com/KumaBase/libe-desk

## 作りたいもの

* リベシティの非公式デスクトップアプリを作りたい
* リベシティ本体と関連サービスを、ひとつのアプリ内で使えるようにしたい
* 起動時はリベシティ本体を表示する
* macOS と Windows で利用できるようにする
* GitHub 上でビルドされ、誰でもダウンロードできるようにする

## 最初に対応するサービス

* リベシティ本体 — https://libecity.com/
* ノウハウ図書館 — https://library.libecity.com/
* スキルマーケット — https://skill.libecity.com/
* リベシティ市場 — https://ichiba.libecity.com/

## 必要な機能

* 左側に各サービスを開くサイドメニューを置く
* 複数のページをタブで開ける
* タブの追加、切り替え、終了ができる
* タブを切り替えても、表示中のページや入力内容を維持する
* 戻る、進む、再読み込みができる
* リベシティの既存ログインをそのまま利用する
* タブ間でログイン状態を共有する
* アプリを閉じても、できるだけログイン状態を維持する
* リベシティ関連ページはアプリ内で開き、外部サイトは標準ブラウザで開く

## 見た目

* リベシティの雰囲気を保つ
* 色、余白、角丸、アイコンなども大きく外さない
* 公式アプリと誤認されないよう、非公式アプリであることを表示する
* 見た目を作り込みすぎず、普段使いできることを優先する

## 将来的な MCP 連携

* 将来的に、AI エージェントから MCP 経由で操作できるようにしたい
* 今回は MCP サーバーや外部通信部分までは作らない
* ただし、将来 MCP から呼び出せるよう、画面操作と内部の操作処理を分けておく

## 使う技術

* Tauri 2 / SolidJS / TypeScript / Vite / Rust / npm
* GitHub Actions / GitHub Releases

## 今回はやらないこと

* リベシティの API 連携
* 独自のログインやサーバー
* MCP サーバーの実装
* 通知、自動アップデート
* スマートフォン版
* 複数アカウント対応
* 起動時のタブ復元
