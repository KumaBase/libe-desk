# Libe Desk 現行仕様

この文書は現行実装の概要です。初期検討時の内容は [requirements.md](./requirements.md) を参照してください。

## 位置づけ

Libe Desk は、リベシティ本体と関連サービスを 1 つのデスクトップアプリから利用するための非公式アプリです。リベシティ運営とは関係ありません。

## 対応環境

- 0.2.0の配布対象：macOS Apple Silicon
- Intel Mac向けの配布物は現在提供しない
- Windows・Linuxは過去のリリースで配布。0.2.0の更新・実機検証には含めない

アプリは Tauri 2、SolidJS、TypeScript、Vite、Rust で構成します。

## 画面と操作

- 起動時にリベシティ本体を開く
- サイドバーから定義済みのリベシティ関連サービスを開く
- 「よく使う」へサービスをピン留めする（リベシティ本体は常時表示）
- リベシティのページに表示される★から、お気に入りユーザーを追加・解除する
- 「お気に入りユーザー」からプロフィールをタブで開き、表示名の変更、並べ替え、削除を行う
- サイドバーは「よく使う」と「ユーザー」をタブで切り替える。選んだタブはローカルストレージへ保存する
- 複数タブの追加、切り替え、終了、ドラッグ＆ドロップによる並べ替え
- ウィンドウ移動用の帯とタブ帯を分離。上の帯をダブルクリックして拡大／復帰
- 初回サイズは原則1400×900。終了時の通常サイズと拡大状態を保存・復元
- アプリメニューの終了と ⌘Q に対応
- 戻る、進む、再読み込み
- 最後のタブを閉じた場合はリベシティ本体を開き直す
- アプリ終了時のタブ構成は復元しない

各タブは個別のネイティブ WebView です。タブを切り替える際は WebView を破棄せず表示・非表示を切り替えるため、開いている間はページ状態を維持します。

## ナビゲーション

- `http`・`https` のページをアプリ内 WebView で開く。userinfo を含むURLは拒否する
- 内部サービス一覧の HTTPS origin から外部サイトへ移動する場合は、確認なしで新しいタブに開く
- 外部サイトとして作成したタブ内の移動・リダイレクトは同じタブで継続する
- `target="_blank"` やURLを指定した `window.open` は、新しいアプリ内タブへ振り分ける
- サイドバーの外部サービスは毎回新しいタブで開く
- `mailto`・`tel` は確認なしでOSの対応アプリへ渡す。それ以外のschemeは拒否する

ページ内のサブリソース通信は各WebサイトとOS WebViewの管理下にあります。

## データ保存と通信

- ページ表示と Cookie・サイトデータの管理には OS WebView を使用する
- Cookie やサイトデータにより、ログイン状態がタブ間や再起動後にも残る場合がある
- 「よく使う」の追加設定はアプリのローカルストレージへ保存する
- ウィンドウの通常時の位置・サイズ・拡大状態はアプリ設定ディレクトリの window-state.json へ保存する。起動時は保存位置のモニター、見つからなければ主モニターの作業領域内に復元する
- お気に入りユーザーはアプリ設定ディレクトリの favorites.json へ保存する。保持するのはユーザー ID と表示名だけで、リベシティの API は使わない
- Libe Desk 独自のログイン機能、自前サーバー、アクセス解析、テレメトリー送信は実装しない
- 表示した Web サイトは、通常のブラウザと同様に各サービスおよびその配信先と通信する

## セキュリティ境界

- アプリ内ナビゲーションはHTTP(S)に限定し、userinfoを含むURLを拒否する
- 内部サービスの分類とリモートページへのIPC権限を分離する。外部サイトを表示しても、そのサイトへアプリ操作の権限を追加しない
- ローカルUIのプラグイン権限は、イベントの購読・解除、ウィンドウのドラッグ・拡大に限定する
- アプリのコマンドは Tauri の ACL 管理下に置き、呼び出し元ごとに許可するコマンドを列挙する
- お気に入りの★を出すため、リベシティのページへスクリプトを1つ注入する。スクリプトは origin を検査してから動き、ページの表示を書き換える以外のことはしない
- `https://libecity.com/*` のリモートページへ開放するコマンドは、お気に入りユーザーの参照・追加・削除の3つに限定する。タブ操作やサービス一覧のコマンドは渡さない
- 注入スクリプトから渡る値は信用せず、ユーザー ID の文字種と長さ、表示名、登録件数をアプリ側で検証する
- 現在のmacOS配布物はDeveloper ID署名とApple公証を行う

脆弱性の報告方法は [SECURITY.md](../SECURITY.md) を参照してください。

## 配布

0.2.0はローカルMacで署名・公証したApple Silicon版のDMGとZIPをGitHub Releasesへ公開します。GitHub Actionsの複数OSビルドは未署名の下書き生成用です。現在は自動更新機能を持たないため、利用者は新しい版を手動でインストールします。

## スコープ外

- リベシティの API 連携
- 独自のログイン機能・自前サーバー
- 通知、自動更新
- スマートフォン版
- 複数アカウント切り替え
- 終了時のタブ構成の復元
- MCP サーバー（将来拡張を考慮した操作層の分離のみ）
