# Libe Desk 現行仕様

この文書は現行実装の概要です。初期検討時の内容は [requirements.md](./requirements.md) を参照してください。

## 位置づけ

Libe Desk は、リベシティ本体と関連サービスを 1 つのデスクトップアプリから利用するための非公式アプリです。リベシティ運営とは関係ありません。

## 対応環境

- 0.1.1の配布対象：macOS Apple Silicon
- Intel Mac向けの配布物は現在提供しない
- Windows・Linuxは過去のリリースで配布。0.1.1の更新・実機検証には含めない

アプリは Tauri 2、SolidJS、TypeScript、Vite、Rust で構成します。

## 画面と操作

- 起動時にリベシティ本体を開く
- サイドバーから定義済みのリベシティ関連サービスを開く
- 「よく使う」へサービスをピン留めする（リベシティ本体は常時表示）
- 複数タブの追加、切り替え、終了、ドラッグ＆ドロップによる並べ替え
- ウィンドウ移動用の帯とタブ帯を分離。上の帯をダブルクリックして拡大／復帰
- 初回サイズは原則1400×900。終了時の通常サイズと拡大状態を保存・復元
- アプリメニューの終了と ⌘Q に対応
- 戻る、進む、再読み込み
- 最後のタブを閉じた場合はリベシティ本体を開き直す
- アプリ終了時のタブ構成は復元しない

各タブは個別のネイティブ WebView です。タブを切り替える際は WebView を破棄せず表示・非表示を切り替えるため、開いている間はページ状態を維持します。

## ナビゲーション

- 内部サービス一覧に明示した HTTPS origin のみアプリ内 WebView で開く
- userinfo や 443 以外のポートを含む URL はアプリ内で開かない
- 制限外の `http`、`https`、`mailto`、`tel` URL は確認ダイアログで承認された場合だけ OS の標準ハンドラーへ渡し、それ以外の scheme は拒否する

ページ内のサブリソース通信や、標準ブラウザで開いた後の動作は各 Web サイトおよびブラウザの管理下にあります。

## データ保存と通信

- ページ表示と Cookie・サイトデータの管理には OS WebView を使用する
- Cookie やサイトデータにより、ログイン状態がタブ間や再起動後にも残る場合がある
- 「よく使う」の追加設定はアプリのローカルストレージへ保存する
- ウィンドウサイズはアプリ設定ディレクトリの window-state.json へ保存する
- Libe Desk 独自のログイン機能、自前サーバー、アクセス解析、テレメトリー送信は実装しない
- 表示した Web サイトは、通常のブラウザと同様に各サービスおよびその配信先と通信する

## セキュリティ境界

- アプリ内ナビゲーション先は scheme、userinfo、ポート、ホスト名で制限する
- 制限外の許可schemeは確認ダイアログを経て `tauri-plugin-opener` から標準ブラウザへ渡す
- ローカルUIのプラグイン権限は、イベントの購読・解除、ウィンドウのドラッグ・拡大に限定する。リモートページにはIPC権限を付与しない
- 現在のmacOS配布物はDeveloper ID署名とApple公証を行う

脆弱性の報告方法は [SECURITY.md](../SECURITY.md) を参照してください。

## 配布

0.1.1はローカルMacで署名・公証したApple Silicon版のDMGとZIPをGitHub Releasesへ公開します。GitHub Actionsの複数OSビルドは未署名の下書き生成用です。現在は自動更新機能を持たないため、利用者は新しい版を手動でインストールします。

## スコープ外

- リベシティの API 連携
- 独自のログイン機能・自前サーバー
- 通知、自動更新
- スマートフォン版
- 複数アカウント切り替え
- 終了時のタブ構成の復元
- MCP サーバー（将来拡張を考慮した操作層の分離のみ）
